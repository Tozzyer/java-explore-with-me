# \# 🎭 Афиша — сервис для организации совместного досуга

# 

# \## 📌 Описание

# Приложение «Афиша» помогает пользователям предлагать события (от выставок до похода в кино), собирать компанию для участия и обмениваться отзывами после мероприятия.  

# Сервис реализован как набор микросервисов с поддержкой REST API, позволяет регистрироваться, управлять событиями, подавать заявки на участие, искать события.

# 

# ---

# 

# \## 🏗 Архитектура

# 

# \### Микросервисы

# \- main-service — основной модуль с бизнес-логикой.

# \- stats-service — модуль для сбора и анализа статистики.

# 

# \### Интерфейсы

# \- Public — доступен всем без регистрации.

# \- Private — для авторизованных пользователей.

# \- Admin — для администраторов.

#
